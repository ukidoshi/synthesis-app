# Веб-сервис учета этапов химического синтеза

Данный проект представляет собой бэкенд (REST API) для системы расчета выхода продукта в многостадийном синтезе. Все названия таблиц, полей и методов строго соответствуют выбранной предметной области[cite: 2].

## Таблицы базы данных

В базе данных реализовано три обязательные таблицы, каскадное удаление данных между которыми запрещено[cite: 2]:

### 1. chemists (Химики-пользователи)
* `id` (bigint, PK) — Уникальный идентификатор химика.
* `full_name` (varchar) — Полное имя химика.
* `email` (varchar) — Уникальная электронная почта.
* `password` (varchar) — Пароль.

### 2. synthesis_stages (Этапы синтеза - услуги)
* `id` (bigint, PK) — Уникальный идентификатор этапа.
* `name` (varchar) — Наименование этапа синтеза.
* `brief_description` (text) — Краткое описание процесса реакции.
* `lifecycle_status` (enum) — Текущий статус карточки этапа, принимающий значения: `draft` (черновик), `published` (опубликован) или `deleted` (удален)[cite: 2].
* `media_image_url` (varchar) — Сгенерированное на латинице название файла изображения, физически хранящегося в MinIO[cite: 2].
* `media_video_url` (varchar) — Сгенерированное на латинице название короткого видео, физически хранящегося в MinIO[cite: 2].
* `yield_percentage` (decimal 5,2) — Поле по предметной области: объем выхода продукта в процентах[cite: 2].
* `reaction_temperature_celsius` (integer) — Поле по предметной области: температура реакции[cite: 2].
* `chemist_id` (bigint, FK) — Внешний ключ на создателя этапа (таблица chemists).
* `created_at` (timestamp) — Системное поле: дата и время создания этапа (формируется на бэкенде)[cite: 2].
* `updated_at` (timestamp) — Системное поле: дата и время публикации/обновления (формируется на бэкенде)[cite: 2].

### 3. synthesis_stage_likes (Лайки)
Связующая таблица для реализации отношения многие-ко-многим между пользователями и услугами[cite: 2].
* `id` (bigint, PK) — Идентификатор записи.
* `synthesis_stage_id` (bigint, FK) — Внешний ключ на этап синтеза.
* `chemist_id` (bigint, FK) — Внешний ключ на химика, поставившего лайк.

## HTTP Методы (REST API)

Все адреса веб-сервиса начинаются с префикса `/api`[cite: 2]. Взаимодействие с базой данных происходит через ORM[cite: 2]. Услуги, находящиеся в статусе `deleted`, на клиент никогда не передаются[cite: 2].

### Домен: Услуга (Этапы синтеза)
В методах изменения данных системные поля игнорируются, так как их передача с клиента запрещена[cite: 2]. Пользователь-создатель временно зафиксирован на бэкенде константой через функцию-singleton[cite: 2].

* **GET** `/api/synthesis-stages` — Получение списка опубликованных этапов[cite: 2]. Метод включает фильтрацию на бэкенде по температуре `?filter_temperature=`[cite: 2]. В ответе возвращается вычисляемый признак (0/1), указывающий, совпадает ли создатель этапа с текущим пользователем[cite: 2].
* **GET** `/api/synthesis-stages/feed/{id?}` — Получение ленты с опубликованными этапами[cite: 2]. Поддерживает навигацию с помощью параметра `?next=true`[cite: 2].
* **GET** `/api/synthesis-stages/draft` — Получение единственного доступного черновика для текущего пользователя (идентификатор в URL не указывается)[cite: 2].
* **POST** `/api/synthesis-stages` — Создание нового черновика и загрузка файлов изображения и видео (принимаются именно как файлы, а не URL)[cite: 2]. Файлы сохраняются в MinIO, а их названия генерируются бэкендом на латинице[cite: 2].
* **PUT** `/api/synthesis-stages/{id}/publish` — Публикация черновика и смена его статуса на опубликованный[cite: 2]. Обратный перевод услуги в статус черновика запрещен[cite: 2].
* **DELETE** `/api/synthesis-stages/{id}` — Удаление этапа[cite: 2]. Применяется логическое удаление (soft delete), при этом пользователю разрешено удалять только свои собственные услуги[cite: 2].
* **POST** `/api/synthesis-stages/{id}/like` — Метод для управления лайками от текущего пользователя[cite: 2]. Принимает JSON с полем `action`, где значение 1 ставит лайк, а 0 — отменяет его[cite: 2].

### Домен: Пользователь (Химики)
Подготовленные заглушки методов для последующего внедрения системы авторизации[cite: 2].
* **POST** `/api/chemists/register` — Регистрация нового химика[cite: 2].
* **POST** `/api/chemists/login` — Аутентификация в системе[cite: 2].
* **POST** `/api/chemists/logout` — Деавторизация[cite: 2].
